# Acceptable Use Policy

## 1. Purpose

This policy defines acceptable use of Nexora Technologies' IT systems, including remote access to internal systems. This is distinct from the Remote Work Policy, which governs where an employee physically performs their work — this policy governs how systems are accessed regardless of work location.

## 2. Remote Access

### 2.1 VPN Requirement

Remote access to internal systems (email, source code repositories, internal tools) is permitted only via the company-managed VPN, from a company-issued device.

### 2.2 Multi-Factor Authentication

All remote access requires multi-factor authentication as described in the Password Policy.

## 3. Prohibited Uses

- Sharing account credentials with another person.
- Installing unauthorized software on company-issued devices.
- Using company systems for activity that violates the Code of Conduct.

## 4. Monitoring

Nexora Technologies reserves the right to monitor use of company systems for security and compliance purposes, in accordance with applicable law.

## 5. Violations

Violations of this policy may result in suspension of system access and disciplinary action under the Code of Conduct.
