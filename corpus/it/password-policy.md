# Password Policy

## 1. Purpose

This policy defines minimum password and authentication requirements for all Nexora Technologies accounts.

## 2. Password Requirements

- Minimum length of 14 characters.
- Must not reuse any of the previous 10 passwords.
- Must be changed every 180 days.

## 3. Multi-Factor Authentication

Multi-factor authentication (MFA) is required for all accounts with access to internal systems, including VPN access described in the Acceptable Use Policy.

## 4. Password Storage

Employees must use the company-approved password manager. Storing passwords in plaintext files or browsers without the approved password manager is prohibited.

## 5. Compromised Credentials

Any suspected compromise of account credentials must be reported to IT Security immediately.
